# Visual reference artifacts

These are the two concept infographics created and discussed during project design:

- `DataBridge_Approved_Architecture_Infographic.png`: approved architecture with Data.gov acquisition, MCP connections and DOT scenario.
- `DataBridge_Full_Tech_Stack_Infographic.png`: technology-layer diagram with LiteLLM, FastAPI, LangGraph, MCP, DuckDB, SurrealDB and Docker.

**Important:** These are illustrative, not executable technical specifications. Their sample UI numbers, syntax, relative component sizes, and icons are conceptual. **The prose architecture, API contracts and acceptance criteria elsewhere in the package are authoritative where any graphic conflicts or suggests a capability not yet implemented.**

Use them for high-level UI layout ideas and hackathon presentation, not to infer that the application is already built.
